# OutfitRep
Hey there! Welcome to my **Outfit Planner** project! This is a simple web app that lets you manage your clothing items and create outfits. You can add your clothing items, view them, and then create outfits with those items. The app uses **Node.js** with **Express** and a **MySQL** database to keep track of everything.

## Features

- **View Clothing Items**: See all the clothing items you’ve added to the system.
- **Add Clothing Items**: You can add new clothing items with details like type, color, and description.
- **View Outfits**: Browse through all the outfits you’ve created.
- **Add Outfits**: Create outfits by choosing from your clothing items and adding some notes.

## Technologies Used

- **Node.js**: The backend server that runs the app.
- **Express.js**: Used for routing and handling HTTP requests.
- **MySQL**: The database that stores your clothing items and outfits.
- **CSS**: Styles for making the app look cute.
- **HTML**: The structure of the web pages.
